# Upload to GitHub & Deploy to Vercel (Step-by-Step)

## Step 1: Fix/Init Git Repo
```
rmdir /s .git
git init
git add .
git commit -m "Initial commit: Bingo Royale project"
```

## Step 2: Create GitHub Repo
1. Go to https://github.com/new
2. Repo name: `bingo-royale` (or your choice)
3. Public/Private, **NO** README/.gitignore (already have)
4. Create repository

## Step 3: Connect & Push to GitHub
```
git remote add origin https://github.com/YOUR_USERNAME/bingo-royale.git
git branch -M main
git push -u origin main
```
Replace `YOUR_USERNAME/bingo-royale.git` with your repo URL.

## Step 4: Deploy to Vercel
1. Install CLI: `npm i -g vercel`
2. Login: `vercel login`
3. In project dir: `vercel --prod`
4. Follow prompts (link to GitHub repo)
5. In Vercel dashboard: Project Settings > Environment Variables > Add `GEMINI_API_KEY`

## Done!
- GitHub: https://github.com/YOUR_USERNAME/bingo-royale
- Vercel: Provided after deploy (e.g., bingo-royale-xxx.vercel.app)

**Notes:** Sockets limited on Vercel free (serverless); use Render for full real-time.
Get GEMINI_API_KEY: https://aistudio.google.com/app/apikey
