# How to Deploy Bingo Royale Project

## Option 1: Vercel (Recommended - Free Tier, Handles Frontend + Serverless API)

**Prerequisites:** Vercel CLI (`npm i -g vercel`), Git repo pushed.

1. Build locally: `npm run build`
2. Install Vercel CLI: `npm i -g vercel`
3. Login: `vercel login`
4. Deploy: `vercel --prod`
5. Set env var in Vercel dashboard: `GEMINI_API_KEY=your_key`
6. Functions auto-detected from `/server` (serverless). Real-time sockets limited; use for non-real-time or upgrade.

**URL:** https://your-project.vercel.app

## Option 2: Render (Free Tier Node Server + Static Frontend)

1. Push to GitHub.
2. New Web Service > Build: `npm install && npm run build`, Start: `npm start`
3. Set env: `GEMINI_API_KEY=your_key`, `NODE_ENV=production`
4. Static Site for frontend/dist if separate.

**URL:** https://your-app.onrender.com

## Option 3: Railway (Similar to Render, Docker-optional)

1. `railway login`
2. `railway new` (link GitHub repo)
3. Add `GEMINI_API_KEY` variable.
4. Build/start cmds auto-detected or set as above.

## Option 4: Docker (Self-host/VPS)

1. Create `Dockerfile`:
```
FROM node:20-alpine
WORKDIR /app
COPY . .
RUN npm ci --only=production
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```
2. `docker build -t bingo-royale .`
3. `docker run -p 3000:3000 -e GEMINI_API_KEY=your_key bingo-royale`

## Notes
- Sockets need persistent server (Render/Railway/VPS); Vercel for static+API.
- Domain: Set in platform dashboard.
- Gemini key required: https://aistudio.google.com/app/apikey
