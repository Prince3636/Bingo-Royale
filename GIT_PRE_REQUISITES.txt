# Prerequisites Before Uploading to GitHub

## 1. Node.js Installed
- Download from https://nodejs.org (LTS version)
- Verify: `node --version` && `npm --version`

## 2. Git Installed
- Download from https://git-scm.com/download/win
- Verify: `git --version`
- Configure (first time): 
  ```
  git config --global user.name "Your Name"
  git config --global user.email "your.email@example.com"
  ```

## 3. GitHub Account
- Create free account: https://github.com/signup
- Verify email

## 4. Project Ready
```
npm install  # Install dependencies (creates node_modules, package-lock.json)
npm run lint  # Fix any TypeScript errors
npm run build # Test build (creates dist/)
```
- Add `.env.local` with `GEMINI_API_KEY` for local testing (don't commit .env files)

## 5. Ignore Sensitive Files
- .gitignore already exists (includes node_modules/, .env*)

## 6. Terminal Ready
- Open VSCode terminal in `d:/bingo-royale`

**After these → Run steps from GITHUB_VERCEL_DEPLOY.txt**

**✅ All set for `git init`, commit, push!**
