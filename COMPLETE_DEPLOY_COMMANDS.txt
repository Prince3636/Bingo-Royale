# BINGO ROYALE - PRODUCTION DEPLOYMENT GUIDE

## Architecture Overview
- **Backend (Socket.IO + Express)**: Deploy to Render.com, Railway, or Fly.io (Supports persistent WebSockets).
- **Frontend (React + Vite)**: Deploy to Vercel (Static hosting) or served directly by the backend.

---

## OPTION 1: Unified All-in-One Deployment (Easiest - Render.com)
Deploy the full stack onto a single Web Service on Render:

1. Push your repository to GitHub.
2. Go to https://render.com -> **New +** -> **Web Service**.
3. Connect your `bingo-royale` GitHub repository.
4. Settings:
   - **Environment**: Node
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
5. Environment Variables:
   - `NODE_ENV`: `production`
   - `CLIENT_URL`: `*` (or your custom domain)
   - `PORT`: `10000` (Render sets PORT automatically)
6. Click **Deploy Web Service**.
   Your backend and frontend will both be live on: `https://bingo-royale-xxx.onrender.com`!

---

## OPTION 2: Split Deployment (Backend on Render + Frontend on Vercel)

### Step 1: Deploy Backend on Render.com
1. Connect repo to Render as a Web Service.
2. Settings:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
3. Environment Variables:
   - `NODE_ENV`: `production`
   - `CLIENT_URL`: `https://your-bingo-app.vercel.app` (add after Vercel deployment)
4. Copy your live backend URL (e.g., `https://bingo-backend.onrender.com`).

### Step 2: Deploy Frontend on Vercel
1. Install Vercel CLI (or import repo on vercel.com):
   ```bash
   npm i -g vercel
   vercel
   ```
2. In Vercel Project Settings -> **Environment Variables**:
   - `VITE_SERVER_URL`: `https://bingo-backend.onrender.com`
3. Redeploy or trigger build:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Update Render's `CLIENT_URL` environment variable to match your Vercel URL!

## Health Check & Verification
Test backend health:
```bash
curl https://your-backend.onrender.com/health
```
Response:
```json
{
  "status": "ok",
  "uptime": 1234,
  "activeRooms": 2,
  "connectedSockets": 8,
  "environment": "production"
}
```
